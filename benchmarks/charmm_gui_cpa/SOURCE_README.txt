There are GROMACS force field files (itp) of 39 different species.
They are mostly CPAs. But, there are also other molecules like water, Au, 4-MBN, MeSCN, Guanidinium, Phosphate...

Name of files:
[A].itp
cgen_[A].itp




cgen_[A] file is a 'charmm36.itp' file of molecule [A] obtained from charmm-gui, including [ defaults ] and each types - force field parameters.
[A] file is a molecular topology file including information of atom and bond connection.
